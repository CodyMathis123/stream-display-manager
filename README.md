# Stream Display Manager

A lightweight native C++ / Win32 tray application for Steam Remote Play. During a confirmed SudoVDA stream, it temporarily switches Windows to the virtual display only. After the stream ends, it restores the physical desktop.

**Native-only project.** The managed .NET / WinForms app is retired. No .NET runtime, browser UI or separate Windows service is needed.

## What it does

- Watches new Steam host streaming log events (never replays old sessions) and observes SudoVDA attachment.
- Saves the current Windows CCD display paths, then switches to SudoVDA-only after topology stabilization.
- Restores the physical monitor on stream completion, SudoVDA detach or normal app exit. Handles Steam restoring the physical desktop itself.
- Does not save the temporary display topology to Windows' persistent display configuration.
- Preserves the virtual-only preference in %LOCALAPPDATA%\StreamDisplayManager\settings.json.
- Provides tray toggles for virtual-only mode and **Start with Windows**, plus manual restoration and resolution capture.
- Installer enables per-user Windows startup by default. The tray can turn startup off.

## Install

For normal installation, download the versioned MSI from [GitHub Releases](https://github.com/CodyMathis123/stream-display-manager/releases) after a Production release has been published. Before the first release, the successful **Windows native build, tests and MSI** Actions workflow provides a verified MSI artifact. It installs a single native executable and a per-user login startup entry. Steam and SudoVDA are installed independently.

**Uninstall managed and old native preview installations before installing this build.** Previous installers had separate product identities; this is a clean native deployment, not a migration.

## Display resolutions and 4K

Use **Capture display modes** in the tray while streaming handheld and then docked. The JSONL events record the active mode, advertised width/height/refresh combinations, whether 3840x2160 appears, and CCD path count. The source is Windows EnumDisplaySettingsExW; advertised modes may differ from those exposed by RDR2.

Logs: %LOCALAPPDATA%\StreamDisplayManager\logs\native-events.jsonl

## Recovery

- Exit the Steam stream normally, or use the tray's **Restore physical display now**.
- Manual command: StreamDisplayManager.Native.exe --restore
- Emergency extended topology: StreamDisplayManager.Native.exe --extend
- The recovery journal lives at %LOCALAPPDATA%\StreamDisplayManager\display-native-restore.bin. The application attempts journal recovery on startup.

Because temporary display changes are not saved in Windows' display database, a reboot normally returns to the last Windows-saved physical desktop arrangement. A driver fault could still require manual intervention.
